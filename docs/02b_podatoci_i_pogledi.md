## 3. Реалистичност на податоците

Кои правила се почитувани: сезонски шилци, нерамномерна популарност на производи, процент откажани нарачки, процент враќања, македонски имиња и градови, `unit_price` според цената важечка на датумот на нарачката, итн. За секое правило дај краток SQL доказ (агрегат) со вистински резултат.

## 4. Проверка на интегритет

- Сите ограничувања се вклучени при полнењето (нема исклучени FK/CHECK).
- `orders.amount` = збир на ставките, со доказ (прашање што враќа 0 неусогласени нарачки).
